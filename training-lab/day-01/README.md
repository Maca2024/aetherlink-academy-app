# Day 1. Weather to ticket triage

Build a small weather decision agent against the deterministic local weather HTTP service, then use the fictional ticket fixture in `data/ticket.json`.

The starter path is `day-01/starter`. The service accepts `city` and `date` query parameters. For Amsterdam on 2026-09-21 the expected decision is `bring umbrella` because the precipitation probability is 70 percent.

Run the shared mocks from `training-lab/README.md` before using the starter.
