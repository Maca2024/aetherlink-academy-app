# Contribution instructions

1. Read [intent.md](intent.md) and [progress.md](progress.md) before changing a lab artifact.
2. Keep all data fictional and local. Never add credentials, client data, remote ticket IDs, or private feedback.
3. Treat `ticket-inputs.md` and `ticket-template.md` as the participant contract. Preserve the selected input's `Current situation` and `Desired situation` wording verbatim.
4. Mark unsupported details `OPEN`. A checker pass is a shape check, not evidence of semantic correctness or a live agent run.
5. The n8n workflow is a local demo. Credentials are selected by the learner in the n8n UI and must never be committed.
6. Before reporting completion, check every relative Markdown link relative to its containing Markdown file and validate JSON syntax.
