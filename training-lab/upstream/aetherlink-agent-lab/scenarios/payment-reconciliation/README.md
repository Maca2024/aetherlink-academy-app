# Fictional payment reconciliation data

The three CSVs under [data/](data/) are synthetic Fictional Reconciliation training inputs:
an internal ledger, PSP settlements, and bank credits. They are optional local
context for the ticket exercise; the first `TICKET-OPS-101` run supplies all
values needed by the ticket itself.

Use the documented identifiers and batch IDs when comparing rows. Keep source
rows visible and label unsupported causes `OPEN`. Amounts are integer minor
EUR values. This fixture is not a production control, a Worldline policy, or a
payout approval source.
